CLI Reference
=============

Pipeline
--------

``dvc repro``
   Run all pipeline stages end-to-end.

``dvc dag``
   Visualize the pipeline DAG.

API
---

``python flask_app/app.py``
   Start the Flask API on port 5000.

Model registry
--------------

``python scripts/promote_model.py``
   Promote the latest Staging model to Production.
